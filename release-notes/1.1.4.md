# Tymor 1.1.4

## ✨ What's new

- Sweeping snow on windows, the Dock, icons, and widgets now pushes it along the surface and sends it falling. Choose **Snow dust** in **Winter → Snow → Cursor sweep** to use the original effect. Snow at the bottom of the screen still gives off dust.
- Snow beds grow into soft, irregular ripples that stay visible as the snow builds up.

## 🐞 Bug fixes

- Minor bug fixes, including smoother snow removal when rolling snowballs.

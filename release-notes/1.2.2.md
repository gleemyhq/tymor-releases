# Tymor 1.2.2

## ✨ What's new

- Open **Arrange Screen Lights…** and **Arrange Window Lights…** directly from the menu bar’s **Lights** menu.
- Arrange screen lights directly on your display. Drag hooks along any enabled edge and use the floating panel to fine-tune their positions.
- If effects or sounds aren’t working, use **Settings → About → Export Diagnostics…** to save a report you can review and share with support.

## ⚡ Improvements

- Select hooks with numbered buttons that highlight the current selection. Switch between screen edges with an inline selector.
- Lower individual hooks up to 120 points in both arrangement editors.
- Move the floating screen-light editor more smoothly while Tymor pauses animated effects on the display you’re editing. Effects resume when you close the editor.

## 🐞 Bug fixes

- Fixed a startup issue that could leave weather and lights invisible even when enabled. If the graphics device is temporarily unavailable, Tymor now retries so effects can start without relaunching the app.
